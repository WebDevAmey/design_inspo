# design_inspo

A small showcase for interface components, built with TanStack Start (TanStack Router on Vite), React and TypeScript.

| Component | Demo page | What it is |
|---|---|---|
| Paper Plane | `public/demos/paper-plane.html` | A message composer. Sending collapses the card, prints the note, folds it into a paper plane and flies it into the Send button. Plain HTML, CSS and JS. |
| Pocket Player | `public/demos/pocket-player.html` | A pill-shaped music player with brushed-metal buttons and a pixel LCD. React (loaded from a CDN) and the Web Audio API. |
| Cassette Deck | `public/demos/cassette-deck.html` | A cassette deck you load by hand: eject, pull the tape out of the side slot, set it down anywhere, slide another in. Spring physics, synthesised key sounds, Web Audio. Double-click a tape (or drop an audio file on it) to play your own audio through the deck. |

## How it fits together

- `src/lib/registry.ts` lists every component (title, blurb, tags, demo path, frame height). The home page and the `/components/$slug` pages are generated from it.
- `src/components/ComponentFrame.tsx` renders a demo in a sandboxed frame, so each component keeps its own CSS, fixed layers and scripts, with a loading state and a Replay button.
- `src/routes/` holds the file-based routes: `__root.tsx` (document and head), `index.tsx` (the showcase) and `components.$slug.tsx` (one component large, with a loader and a not-found state). `src/routeTree.gen.ts` is generated by the router plugin.

To add a component, drop its standalone HTML in `public/demos/` and add one entry to `src/lib/registry.ts`.

## Run it

```sh
npm install
npm run dev      # http://localhost:3000
npm run build    # server build in .output/
npm start        # serve the build
```

## Deploy

The server is packaged by Nitro, which detects Vercel automatically. Push to `main` to update the production deployment.
